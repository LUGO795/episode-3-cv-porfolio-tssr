Épisode 3 Construire la barre de navigation

  • Niveau Grand débutant
  • Langages HTML5 · CSS3 · premier JavaScript
  • Durée indicative 35 à 45 min de vidéo · 2 h en séance
  • Fichier modifié index.html (config.js inchangé)

Objectif de l'épisode

Notre page devient une vraie interface : une barre de menu fixe en verre dépoli,
des liens soulignés par une animation qui s'ouvre depuis le centre, un menu burger sur mobile,
et un bouton clair / sombre qui fait basculer toute la page et retient le choix pour la visite suivante.
Vous allez écrire vos premières lignes de JavaScript.

Partie 2

Objectif pédagogique

À la fin de cet épisode, vous serez capable de construire une barre de navigation
responsive et accessible et d'écrire un petit programme JavaScript
qui réagit aux actions du visiteur.

Ce que vous saurez faire

  • Utiliser un composant Bootstrap (la navbar) et l'habiller avec vos propres variables CSS.
  • Fixer un élément en haut de l'écran et créer un effet de verre dépoli.
  • Créer une animation au survol avec un pseudo-élément ::before.
  • Rendre un bouton icône accessible avec aria-label, aria-expanded et aria-controls.
  • Écrire du JavaScript : récupérer un élément, écouter un clic ou un défilement, modifier un attribut ou une classe.
  • Mémoriser un choix dans le navigateur avec localStorage.
  • Afficher une notification annoncée aux lecteurs d'écran.

Les nouveaux mots de cet épisode

Les mots des épisodes précédents sont dans les listes de l'épisode 1 et de l'épisode 2.

Navbar
La « barre de navigation » : le menu en haut du site. Bootstrap en fournit un modèle complet.
Menu burger
Le bouton à trois barres qui, sur mobile, déplie et replie le menu.
Point de rupture
Une largeur d'écran à partir de laquelle la mise en page change.
Pour Bootstrap, lg = 992 pixels.
Classe utilitaire
Une petite classe Bootstrap qui fait une seule chose : ms-auto (marge gauche automatique), p-1 (petite marge intérieure)…
!important
Un mot-clé qui donne la priorité à une déclaration CSS sur les déclarations normales, quel que soit leur poids.
ARIA
Des attributs (aria-label, aria-expanded…) qui décrivent les éléments aux lecteurs d'écran.
Toast
Une petite notification qui apparaît quelques secondes, puis disparaît.
JavaScript
Le langage de programmation du navigateur : il rend la page interactive.
Constante (const)
Une boîte nommée qui contient une valeur qu'on ne remplacera pas.
Fonction
Un bloc de code nommé, qu'on peut exécuter (« appeler ») autant de fois qu'on veut.
Événement
Une action qui se produit sur la page : un clic, un défilement, une touche… On peut « l'écouter » pour y réagir.
DOM
La page telle que le navigateur la garde en mémoire. Le JavaScript la modifie : ajouter une classe, changer un texte, un attribut.
localStorage
Un petit espace de stockage du navigateur, propre à chaque site, qui garde des informations entre deux visites.

      const nav = document.getElementById('mainNav');
